# Codexdemo

HTML・CSS・JavaScript だけで動く、日本語の ToDo アプリです。依存パッケージのインストールは不要です。

## 起動方法

`index.html` をブラウザで開いてください。

ローカル HTTP サーバーを使う場合は、Python 3 がある環境でリポジトリのルートから実行します。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

同じ端末のブラウザで `http://127.0.0.1:8000` を開きます。終了するにはターミナルで Ctrl+C を押します。

## 使い方

- タスクを入力し、「追加」ボタンまたは Enter キーで追加します。
- チェックボックスで完了・未完了を切り替えます。
- 「削除」ボタンでタスクを削除します。
- 未完了件数と全件数が一覧の上に表示されます。

空白だけのタスクは追加できません。入力は200文字までです。タスクはメモリ内で管理しているため、ページを再読み込みすると消えます。

## ファイル構成

- `index.html`: 画面構成
- `style.css`: 見た目とスマートフォン向けのレイアウト
- `app.js`: タスク追加・完了切り替え・削除の処理

## 手動での動作確認

1. 最初は空の一覧と「未完了 0 件 / 全 0 件」が表示されることを確認します。
2. ボタンと Enter キーでそれぞれタスクを追加します。
3. チェックを入れたり外したりして、取り消し線と件数が更新されることを確認します。
4. タスクを削除し、最後の1件を削除すると空の案内が戻ることを確認します。
5. 空白だけの入力が拒否され、HTML のような文字列がそのままテキストとして表示されることを確認します。
6. 狭い画面や長いタスク名でも操作できること、Tab・Enter・Space キーで操作できることを確認します。
